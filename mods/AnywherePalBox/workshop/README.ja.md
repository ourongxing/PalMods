# どこでもパルボックス

1.0.0 · ourongxing

K キーで、フィールドやダンジョンからゲーム標準のパルボックスを開けます。パルの確認、整理、入れ替えに便利です。

自分のギルドの拠点内では、その拠点のパルボックスを開きます。フィールドやダンジョンでは、自分のギルドで建築物が最も多い拠点を選びます。建築物の数が同じ場合は、プレイヤーに最も近い拠点を選びます。キーを押すたびに選び直します。ギルドに拠点があり、対応するパルボックスのモデルを取得できる必要があります。

ゲーム標準のパルボックス画面と終了処理を使用します。他のメニューが開いている間、画面のフェード中、プレイヤーの準備が整っていないときはキー入力を無視します。他のギルドの拠点内ではパルボックスを開かず、自分のギルドの拠点への切り替えも行いません。

初期設定のキーは K です。インストール先の `Mods/NativeMods/UE4SS/Mods/AnywherePalBox/Scripts/config.lua` を編集し、`Hotkey = "K"` を `"J"` や `"F6"` などの UE4SS キー名に変更して、ゲームを再起動してください。大文字と小文字は区別しません。単一キーのみ対応し、設定が見つからない場合や無効な場合は K を使用して UE4SS ログに通知します。

ローカルのシングルプレイで、ダンジョンを含めて動作確認済みです。マルチプレイは未検証です。

必要な mod（UE4SSExperimentalPW）をサブスクライブして有効にしてください。その後、ゲームの mod 管理でこの mod を有効にし、ゲームを再起動してください。
