# 随处打开终端

1.0.0 · ourongxing

按 K 即可随处打开原版帕鲁终端，支持野外和地下城，方便查看、整理和调整帕鲁。

在自己公会的据点内使用时，打开当前据点的终端。在野外或地下城使用时，选择自己公会建筑物最多的据点；建筑物数量相同时，选择距离玩家最近的据点。每次按键都会重新选择。需要公会已有据点，且对应终端模型可用。

使用原版终端界面与关闭流程。其他菜单打开、淡入淡出或玩家尚未就绪时忽略按键；位于其他公会据点内时不会打开终端，也不会转到自己公会的据点。

快捷键默认 K。编辑安装目录下的 `Mods/NativeMods/UE4SS/Mods/AnywherePalBox/Scripts/config.lua`，将 `Hotkey = "K"` 改成 `"J"`、`"F6"` 等 UE4SS 按键名称，保存后重启游戏。按键名称不区分大小写，仅支持单个按键；配置缺失或无效时回退到 K，并在 UE4SS 日志中提示。

已在本机单人游戏验证，包括地下城。多人游戏尚未验证。

先订阅并启用依赖：UE4SSExperimentalPW。然后在游戏的 mod 管理中启用本 mod，并重新启动游戏。
