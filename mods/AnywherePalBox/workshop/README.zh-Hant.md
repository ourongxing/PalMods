# 隨處開啟終端

1.0.0 · ourongxing

按 K 即可隨處開啟原版帕魯終端，支援野外與地下城，方便查看、整理及調整帕魯。

在自己公會的據點內使用時，開啟目前據點的終端。在野外或地下城使用時，選擇自己公會建築物最多的據點；建築物數量相同時，選擇距離玩家最近的據點。每次按鍵都會重新選擇。公會需要已有據點，且對應終端模型可用。

使用原版終端介面與關閉流程。其他選單開啟、淡入淡出或玩家尚未就緒時忽略按鍵；位於其他公會據點內時不會開啟終端，也不會轉到自己公會的據點。

快捷鍵預設 K。編輯安裝目錄下的 `Mods/NativeMods/UE4SS/Mods/AnywherePalBox/Scripts/config.lua`，將 `Hotkey = "K"` 改成 `"J"`、`"F6"` 等 UE4SS 按鍵名稱，儲存後重新啟動遊戲。按鍵名稱不區分大小寫，僅支援單一按鍵；設定缺失或無效時回復為 K，並在 UE4SS 日誌中提示。

已在本機單人遊戲驗證，包括地下城。多人遊戲尚未驗證。

請先訂閱並啟用必要模組：UE4SSExperimentalPW。接著在遊戲的模組管理中啟用本模組，並重新啟動遊戲。
