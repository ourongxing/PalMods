# Awakening Trust / 信頼覚醒

0.3.0 · ourongxing

信頼度を上げる楽しさも、覚醒させる手応えも、もっと大きく。覚醒後の信頼度ボーナスを大幅に強化して、パルごとの種族値の差を縮めます。お気に入りのパルを、もっと活躍させたい人に。

## どんな効果？

- 覚醒した時点で効果が出ます。信頼度を最大にする必要はありません。信頼度が高いほど、強化の恩恵も大きくなります。
- 通常の信頼度最大時に、HP・攻撃・防御の種族値の合計が 450 に届かないパルは、元の比率を保ったまま合計 450 まで引き上げます。
- もともと合計 450 以上のパルはそのまま。強いパルが弱くなることはありません。
- 未覚醒のパルは通常どおり。ゲーム本来の覚醒ボーナスもそのまま加算されます。

## どれくらい強くなる？

信頼度最大のツッパニャンとベイントールを、HP / 攻撃 / 防御の順に比べてみると：

- **ツッパニャン**：125 / 107 / 107 → 約 165.93 / 142.04 / 142.04。合計 **339 → 450**。
- **ベイントール**：160 / 150 / 146。合計がすでに **456** なので、変更はありません。

ここで示しているのは、信頼度による成長を含めた種族値です。ステータス画面の最終的な数値ではありません。ゲーム本来の覚醒ボーナスは別途加算されます。

## マルチプレイ

シングルプレイ、プレイヤーがホストする協力プレイ、Windows 専用サーバーに対応しています。マルチプレイでは、クライアントとサーバーの両方に、それぞれ対応するビルドを導入してください。

## 導入方法

前提 Mod の **UE4SSExperimentalPW** をサブスクライブして有効にし、ゲームの Mod 管理で本 Mod を有効にしてください。その後、ゲームを完全に終了して起動し直してください。

Windows 専用サーバーにも同じワークショップパッケージと前提 Mod を導入し、再起動してください。パッケージにはサーバー専用 DLL を同梱しています。
