# Awakening Trust / 信赖觉醒

0.3.0 · ourongxing

让信赖度和觉醒更有用。帕鲁觉醒后，信赖度带来的属性加成会大幅提升，拉近不同帕鲁之间的种族值差距，让你喜欢的帕鲁也能有更好的表现。

## 怎么生效？

- 觉醒后就会生效，不用等到信赖度满级。信赖度越高，增强效果越明显。
- 满信赖度时，原版生命、攻击、防御三项种族值加起来不足 450 的，会按原来的比例补到 450。
- 本来就达到或超过 450 的帕鲁保持不变，强势帕鲁不会被削弱。
- 没觉醒的帕鲁照旧。原版觉醒自带的属性加成也会保留。

## 能增强多少？

拿满信赖度的捣蛋猫和唤夜兽来比，按生命 / 攻击 / 防御排列：

- **捣蛋猫**：125 / 107 / 107 → 约 165.93 / 142.04 / 142.04，总和从 **339 提升到 450**。
- **唤夜兽**：160 / 150 / 146，总和已经是 **456**，保持不变。

这里比较的是加上信赖度成长后的种族值，不是面板上的最终属性；原版觉醒的额外加成另算。

## 联机支持

支持单机、玩家开房和 Windows 专用服务器。联机时，客户端和服务器需要分别安装对应版本。

## 安装

订阅并启用前置 Mod **UE4SSExperimentalPW**，在游戏的 Mod 管理中启用本 Mod，然后完全退出并重新启动游戏。

Windows 专用服务器请安装同一工坊包及前置 Mod，再重启服务器。包内已包含独立服务端 DLL。
