# Awakening Trust / 信賴覺醒

0.3.0 · ourongxing

讓信賴度和覺醒更有用。帕魯覺醒後，信賴度帶來的能力加成會大幅提升，縮小不同帕魯之間的種族值差距，讓你喜歡的帕魯也能有更好的表現。

## 如何生效？

- 覺醒後就會生效，不必等到信賴度滿級。信賴度越高，強化效果越明顯。
- 滿信賴度時，原版生命、攻擊、防禦三項種族值加起來不足 450 的，會按原本的比例補到 450。
- 原本就達到或超過 450 的帕魯維持不變，強勢帕魯不會被削弱。
- 沒覺醒的帕魯照舊。原版覺醒自帶的能力加成也會保留。

## 能強化多少？

以滿信賴度的搗蛋貓和喚夜獸為例，依生命 / 攻擊 / 防禦排列：

- **搗蛋貓**：125 / 107 / 107 → 約 165.93 / 142.04 / 142.04，總和從 **339 提升至 450**。
- **喚夜獸**：160 / 150 / 146，總和已經是 **456**，維持不變。

這裡比較的是加上信賴度成長後的種族值，不是面板上的最終能力；原版覺醒的額外加成另計。

## 多人連線

支援單人、玩家開房及 Windows 專用伺服器。連線時，用戶端與伺服器需要分別安裝對應版本。

## 安裝

訂閱並啟用前置 Mod **UE4SSExperimentalPW**，在遊戲的 Mod 管理中啟用本 Mod，然後完全退出並重新啟動遊戲。

Windows 專用伺服器請安裝同一工坊套件與前置 Mod，再重新啟動伺服器。套件內已包含獨立的伺服器端 DLL。
