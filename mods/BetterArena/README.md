# Better Arena / 更好的竞技场

开发版 0.1.0 · ourongxing

竞技场主菜单新增“扫荡”，与“挑战、PVP、观战”并列。点击后进入相同样式的难度选择页；选择任一已通关难度，即刻发放一次对应的重复通关奖励，并按当前胜利积分、段位差倍率增加排名积分。未通关难度不可扫荡，普通“挑战”仍正常进入战斗。

领取成功后播放原生奖励横幅动画与音效，显示本次实际获得的道具数量和增加的 RP，数秒后自动收起，可继续操作。

玩家积分段位决定共享每日额度：铜杯 1、银杯 2、金杯 3、白金杯 4、钻石杯 5、大师杯 6、传奇杯 7。各挑战难度共用次数；按游戏内总天数刷新，不累计。当天升段提高总额度，不重置已用次数。

当前开发范围为单机和本机房主；联机客户端及专用服务器尚不支持。需要 UE4SS Experimental (Palworld)。不覆盖竞技场奖励表或游戏设置，读取其他 mod 修改后的当前奖励与积分。

## 本地开发

在仓库根目录运行 `python tools/build.py BetterArena` 打包。运行 `python mods/BetterArena/tests/run.py` 做离线回归检查。

关闭游戏后运行 `mods/BetterArena/tools/install_local.ps1` 安装到现有本地 UE4SS 目录。尚未准备 Workshop 发布，不迁移其他 mod。

## 配置和数据

`Scripts/config.lua` 的 `DailyLimits` 按铜杯至传奇杯依次配置每日次数，支持 0～100。`Enabled` 可关闭功能。

额度记录在 `%LOCALAPPDATA%/Pal/Saved/BetterArena/`，每个世界与玩家独立。安装更新不覆盖这些数据；备份游戏时也应备份此目录。

背包空间不足时拒绝扫荡。额度先写入磁盘，再发奖与积分；如果过程中出错或崩溃，为避免重复发放，当天暂停该玩家的扫荡，下一游戏日恢复。磁盘记录损坏时不自动清空重试。该记录与游戏存档是分别保存的，手动回档不会自动退还额度。
