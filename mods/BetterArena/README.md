# Better Arena / 更好的竞技场

开发版 0.1.0 · ourongxing

竞技场主菜单新增“扫荡”，与“挑战、PVP、观战”并列。点击后进入相同样式的难度选择页；选择任一已通关难度，即刻发放一次对应的重复通关奖励，并按当前胜利积分、段位差倍率增加排名积分。未通关难度不可扫荡，普通“挑战”仍正常进入战斗。

所有 NPC 竞技场难度的首通物品、重复通关物品和胜利基础积分默认两倍，普通挑战与扫荡统一使用同一倍率，原生奖励预览同步变化。只调整数量，不改变掉落概率、失败扣分、PVP 积分或每日扫荡次数。

领取成功后播放原生奖励横幅动画与音效，显示本次实际获得的道具数量和增加的 RP，数秒后自动收起，可继续操作。

玩家积分段位决定共享每日额度：铜杯 1、银杯 3、金杯 5、白金杯 7、钻石杯 9、大师杯 11、传奇杯 13。各挑战难度共用次数；按游戏内总天数刷新，不累计。当天升段提高总额度，不重置已用次数。

当前开发范围为单机和本机房主；联机客户端及专用服务器尚不支持。需要 UE4SS Experimental (Palworld) 和 PalSchema。PalSchema 加载奖励表及 NPC 胜利基础分补丁，Lua 只处理扫荡；两种玩法读取同一份生效数据，不再次翻倍。补丁以 Palworld 1.0.5 原版奖励和基础胜利积分 50 为基准；与其他奖励表 mod 的覆盖顺序会影响结果。

## 本地开发

在仓库根目录运行 `python tools/build.py BetterArena` 打包。运行 `python mods/BetterArena/tests/run.py` 做离线回归检查。

关闭游戏后运行 `mods/BetterArena/tools/install_local.ps1` 安装到现有本地 UE4SS 目录。尚未准备 Workshop 发布，不迁移其他 mod。

## 配置和数据

`Scripts/config.lua` 的 `DailyLimits` 按铜杯至传奇杯依次配置每日次数，默认 `{1, 3, 5, 7, 9, 11, 13}`，各项支持 0～100。mod 加载后直接生效，不再提供 `Enabled` 开关。

`RewardMultiplier = 2` 统一控制普通挑战和扫荡的奖励倍率；设为 `1` 使用原版基础奖励，`3` 为三倍，只接受 `1～10` 的整数，不接受小数、零或超出范围的值。物品的最小／最大数量及 NPC 胜利基础分分别乘倍率，积分再沿用游戏的段位差倍率与原生取整。

修改倍率：先关闭游戏，打开安装目录中的 `BetterArena/ConfigureRewards.cmd`，输入 1～10；工具同步更新 `config.lua` 和 `PalSchema/mods/BetterArena/` 下的两份补丁，再启动游戏。也可以手动编辑 `config.lua` 后运行同目录的 `ApplyConfig.ps1`。仅编辑倍率并重启不足以生成 PalSchema 补丁；启动时会校验配置与已应用倍率一致。

本地配置位于 `<游戏目录>/Mods/NativeMods/UE4SS/Mods/BetterArena/Scripts/config.lua`。`DailyLimits` 修改后直接完整重启即可。安装更新默认保留已有配置并生成对应倍率的补丁；旧配置没有 `RewardMultiplier` 时默认为 `2`。安装脚本的 `-ResetConfig` 可显式恢复随包默认配置。

额度记录在 `%LOCALAPPDATA%/Pal/Saved/BetterArena/`，每个世界与玩家独立。安装更新不覆盖这些数据；备份游戏时也应备份此目录。

背包空间不足时拒绝扫荡。额度先写入磁盘，再发奖与积分；如果过程中出错或崩溃，为避免重复发放，当天暂停该玩家的扫荡，下一游戏日恢复。磁盘记录损坏时不自动清空重试。该记录与游戏存档是分别保存的，手动回档不会自动退还额度。
