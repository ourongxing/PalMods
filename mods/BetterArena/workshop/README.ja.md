# Better Arena / より良いアリーナ

1.1.1 · ourongxing

> 掃討のロック表示とクラッシュを修正。

---

一度クリアしたアリーナは、毎日戦い直さずに報酬を獲得。初回クリアで掃討を解放し、プレイヤーのランクが上がるほど1日の掃討回数が増えます。

## 使い方

アリーナのメインメニューで**掃討**を選び、クリア済みの難易度を選択すると、その難易度の周回報酬と勝利ランクポイントを即時獲得できます。戦闘や待ち時間はありません。報酬バナーのアニメーションと効果音が再生され、実際に獲得したアイテムと RP が表示されます。

- **難易度ごとに解放**：各難易度を通常の戦闘で一度クリアする必要があります。元の挑戦メニューも利用できます。
- **ランクで回数が増加**：プレイヤーのブロンズからレジェンドまで、1日 **1 / 3 / 5 / 7 / 9 / 11 / 13 回**。選んだ挑戦の難易度には依存しません。
- **全難易度で回数を共有**：ゲーム内の日付が進むとリセットされ、翌日への繰り越しはありません。当日の昇格では上限の差分が追加され、使用済み回数は維持されます。
- **標準で報酬2倍**：通常の NPC 戦と掃討の両方で、初回・周回のアイテム数と勝利基礎 RP が2倍になります。ランク差による RP 計算はゲーム本来の仕様に従います。

## 導入

1. 前提 Mod の UE4SSExperimentalPW と PalSchema をサブスクライブして有効にします。
2. ゲームの Mod 管理で本 Mod を有効にします。
3. ゲームを完全に終了してから再起動します。

Windows 専用サーバーでは、サーバーとクライアントの両方に本 Mod、UE4SSExperimentalPW、PalSchema を導入して有効にし、両方を完全に再起動してください。

## 設定

Palworld のインストール先にある `Mods/NativeMods/UE4SS/Mods/BetterArena/` を開きます。

マルチプレイの報酬倍率と1日の回数は、ホストまたはサーバーの設定に従います。サーバーの設定変更後はサーバーを再起動してください。

- **報酬倍率**：ゲームを終了し、`Scripts/config.lua` の `RewardMultiplier` を **1～10 の整数**に変更して保存後、再起動します。初期値は2、1で原版の基礎報酬。ワールドに入ると自動適用されます。
- **1日の回数**：`Scripts/config.lua` の `DailyLimits` を編集します。ブロンズからレジェンドの順で、各値は0～100。保存後にゲームを完全に再起動してください。

初回起動時に PalSchema の自動再読み込みを有効にします。無効だった場合は、もう一度完全に再起動して設定を完了してください。この設定は他の PalSchema Mod にも適用されます。

## 利用上の注意

ソロ、協力プレイのホスト、Windows 専用サーバーに対応します。マルチプレイの掃討では、ホストまたはサーバーがクリア記録、残り回数、所持品を確認して報酬を付与します。表示はゲームの言語に従い、日本語・英語・簡体字中国語・繁体字中国語に対応します。

報酬パッチは Palworld 1.0.5 の原版データを基準に、アリーナの報酬テーブルと NPC 勝利基礎 RP を上書きします。同じデータを変更する Mod とは競合する場合があります。ドロップ確率、敗北時の減点、PVP の RP は変更しません。

使用回数は `%LOCALAPPDATA%/Pal/Saved/BetterArena/` にワールド・プレイヤー別で保存されます。セーブのバックアップや移行時は、このフォルダーも一緒に保存してください。

専用サーバーの使用回数は、サーバーディレクトリ内の `Pal/Saved/BetterArena/` に保存され、クライアントのソロ記録とは別に管理されます。
