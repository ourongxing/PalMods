# Better Arena / 更好的竞技场

1.1.0 · ourongxing

打过一次的竞技场，不必每天重打。首通解锁一键扫荡，段位越高，每天可扫荡的次数越多。

## 使用方法

竞技场主菜单选择**扫荡**，再选择已通关的难度，即刻获得该档重复通关奖励和胜利排名积分，无需等待或进入战斗。领取时播放奖励动画与音效，显示实际到账的道具和 RP。

- **每档首通解锁**：各难度需要分别正常通关一次；原来的挑战入口保留。
- **段位决定次数**：按玩家积分段位，青铜至传奇每日分别为 **1 / 3 / 5 / 7 / 9 / 11 / 13 次**，与所选挑战难度无关。
- **全部难度共用次数**：按游戏内天数刷新，不累计；当天升段补充额度差值，不重置已用次数。
- **默认双倍奖励**：普通挑战和扫荡统一使用两倍物品与胜利基础积分，包含首通和重复通关奖励；积分仍按原版段位差计算。

## 安装

1. 订阅并启用前置 Mod：UE4SSExperimentalPW、PalSchema。
2. 在游戏的 Mod 管理中启用本 Mod。
3. 完全退出游戏，再重新启动。

Windows 专用服务器：服务器和客户端均需安装并启用本 Mod、UE4SSExperimentalPW 和 PalSchema，然后完整重启两端。

## 配置

配置目录为 Palworld 安装目录下的 `Mods/NativeMods/UE4SS/Mods/BetterArena/`。

联机时，奖励倍率和每日次数以主机或服务器的配置为准；修改服务端配置后重启服务器。

- **奖励倍率**：关闭游戏，编辑 `Scripts/config.lua` 的 `RewardMultiplier`，输入 **1～10 的整数**，保存后重新启动。默认 2，设为 1 使用原版基础奖励，进入世界后自动应用。
- **每日次数**：编辑 `Scripts/config.lua` 中的 `DailyLimits`，依次对应青铜至传奇，各项支持 0～100，保存后完整重启游戏。

首次启动会自动开启 PalSchema 的自动重载；如果此前关闭，请再完整重启一次完成设置。此开关也适用于其他 PalSchema Mod。

## 使用须知

支持单机、本机房主和 Windows 专用服务器。联机扫荡由主机或服务器校验通关、次数和背包，再发放奖励。界面跟随游戏语言，支持简体中文、繁体中文、日语和英语。

奖励补丁基于 Palworld 1.0.5 原版数据，会覆盖竞技场奖励表及 NPC 胜利基础分；其他修改相同数据的 Mod 可能冲突。不会修改掉落概率、失败扣分或 PVP 积分。

次数记录保存在 `%LOCALAPPDATA%/Pal/Saved/BetterArena/`，按世界和玩家分别记录。备份或迁移存档时请一并保留。

专用服务器的次数记录位于服务器目录下的 `Pal/Saved/BetterArena/`，与客户端单机记录分开保存。
