# 一括便利収納の機能拡張

1.0.0 · ourongxing

ゲーム標準の「一括便利収納」を拡張します。チェストのカテゴリーやフィルター設定に従って、インベントリのアイテムを対応するチェストに自動で収納します。同じアイテムをあらかじめ入れておく必要はなく、空のチェストにも収納できます。

拠点の外でも、メイン拠点のチェストにまとめて収納できます。メイン拠点には、所属ギルドの中で建築物が最も多い拠点を選びます。建築物の数が同じ場合は、プレイヤーから最も近い拠点を選びます。拠点内で使う場合は、現在いる拠点に収納します。

インベントリを開き、標準の「一括便利収納」ボタンまたはショートカットキーを使ってください（キーボードの初期設定は R）。各チェストに収納できるアイテムのカテゴリーを設定しておくと、カテゴリーに従って収納できます。標準の確認画面と除外リストをそのまま利用し、チェストの容量、カテゴリー設定、アクセス権限に従います。パルのタマゴも、そのカテゴリーを許可していて空きスロットのあるチェストに収納できます。

拠点内で大量のアイテムを収納する際の追加スキャンを避けるため、画面ではチェストのカテゴリー、アクセス権限、空き容量を事前判定しません。選択できても収納できない場合があり、そのアイテムはインベントリに残ります。

現在、ローカルのシングルプレイで動作確認済みです。マルチプレイでは、サーバー側に本 mod の DLL、クライアント側に Lua が必要です。クライアント側だけに導入してもサーバーの収納ルールは変更できません。マルチプレイは未検証です。

必要なmod（UE4SSExperimentalPW）をサブスクライブして有効にしてください。その後、ゲームのmod管理でこのmodを有効にし、ゲームを再起動してください。
