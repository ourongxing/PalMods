# 更好的快速收纳

1.0.0 · ourongxing

增强原版“批量快速收纳”：按箱子的分类和过滤设置，自动将背包物品收纳到对应箱子，无需箱子里已有同类物品。空箱也能直接收纳。

在野外也能将物品快速收纳到主据点的箱子。主据点是所属公会中建筑物最多的据点；建筑物数量相同时，选择距离玩家最近的据点。在据点内使用时，仍收纳到当前据点。

打开背包，使用原版“批量快速收纳”按钮或快捷键即可（键盘默认 R）。先设置各箱子允许收纳的物品分类，即可按分类收纳。保留原版确认窗口和除外项目表，遵守箱子的容量、分类设置及访问权限；帕鲁蛋也可存入允许该分类且有空格的箱子。

目前已在本机单人游戏测试。多人游戏需要服务器加载本 mod 的 DLL、客户端加载 Lua；仅客户端安装无法改变服务器的收纳规则，多人游戏尚未验证。

先订阅并启用依赖：UE4SSExperimentalPW。然后在游戏的mod管理中启用本mod，并重新启动游戏。
