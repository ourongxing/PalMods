# 更好的快速收納

1.0.0 · ourongxing

強化原版「批量快速收納」：依照箱子的分類與篩選設定，自動將背包道具收納至對應的箱子，無須箱子內已有同類道具。空箱也能直接收納。

在野外也能將道具快速收納至主據點的箱子。主據點是所屬公會中建築物最多的據點；建築物數量相同時，選擇距離玩家最近的據點。在據點內使用時，仍收納至目前所在的據點。

開啟背包，使用原版「批量快速收納」按鈕或快捷鍵即可（鍵盤預設 R）。先設定各箱子允許收納的道具分類，即可按分類收納。保留原版確認視窗與除外項目表，遵守箱子的容量、分類設定及存取權限；帕魯蛋也可存入允許該分類且有空格的箱子。

使用收納快捷鍵或按鈕後才開始分幀檢查，逐個更新道具灰顯。開啟背包和一般整理不會啟動檢查，掃描期間點擊整理會取消任務；可收納道具逐個加入清單，確認時處理已加入的道具。野外收納不要求載入遠處箱子，實際能否存入由伺服器驗證。

目前已在本機單人遊戲測試。多人遊戲需要伺服器載入本模組的 DLL、用戶端載入 Lua；僅用戶端安裝無法改變伺服器的收納規則，多人遊戲尚未驗證。

請先訂閱並啟用必要模組：UE4SSExperimentalPW。接著在遊戲的模組管理中啟用本模組，並重新啟動遊戲。

收納時先在所有目標箱子中合併已有的同類堆疊，再將剩餘道具放入空格。

帕魯搬運新增堆疊優先：同一搬運優先級內，優先選擇有未滿同類堆疊的箱子；多個箱子都能堆疊時仍選擇最近的。已滿堆疊不加優先，原版箱子優先級、分類篩選和生產需求繼續生效。需要主機或伺服器載入 DLL，新搬運任務才會使用此規則。

普通可堆疊物品的單格上限統一為 99,999，背包、箱子、礦場、伐木場及其他物品容器共用；礦場和伐木場的滿倉停工判斷同步使用此上限，不改變產量或工作速度。裝備、帕魯蛋等獨立實例物品保留原規則，分類篩選、存取權限和格數限制仍生效。現有物品數量不會被截斷，也不會自動合併分散堆疊。無須另裝堆疊數量模組；解除安裝前請拆分超過原版上限的堆疊。礦場停工/恢復、存檔重新載入及多人遊戲仍需遊戲內驗證。
