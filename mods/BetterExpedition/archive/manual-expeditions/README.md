# Better Expedition / 更好的远征

当前为暂停使用的实验实现：实机反馈严重掉帧，移除逐帧 HUD 回调后仍未解决。已从本机游戏加载目录移除，不建议安装；以下行为说明仅描述当前实现，性能问题尚未定位。

保留原版远征任务、解锁条件、组队与战力规则。远征持续进行，只有玩家选择结束才结算；原版“取消远征”操作改为结束并按已进行时间领取奖励。

结算物品 = 原版在当前队伍战力下的一次远征实际奖励 ×（已进行时间 ÷ 该战力及研究加成下的原版耗时）。相同战力、相同原版耗时获得原版奖励；一半时间对应一半，两倍时间对应两倍，没有原定时长上限。

沿用原版奖励抽取、战力倍率、研究加成和奖励容器。物品不足一个时按小数概率取整，避免短远征无条件至少给一个物品；整数比例保持准确。随机奖励的同比例指期望收益，不保证每次抽中同一种道具。

使用原版保存的远征开始时间，计时遵循游戏世界时钟；退出和重进后保留任务，不另建计时存档。安装前已在进行的任务也会改为手动结束。卸载后恢复原版到时完成。

没有整件奖励时仍能正常结束并重新派遣，不会卡在空领奖箱。奖励先进入原版远征设施的容器，再通过原版“全部领取”拿进背包。

依赖 UE4SS Experimental PW；当前原生接口仅支持 Palworld 1.0.5.102999，接口或二进制不匹配时不启用修改。已完成单机隔离世界的提前结束、超时持续、重启保留、领取及零奖励返回验证；联机、专用服务器与经验收益未验收。细节见 [验收记录](docs/VALIDATION.md)。

构建：`python tools/build.py BetterExpedition`。测试：`python mods/BetterExpedition/tests/run.py`。关闭游戏后运行 `mods/BetterExpedition/tools/install_local.ps1` 安装到本地 UE4SS Mods 目录。
