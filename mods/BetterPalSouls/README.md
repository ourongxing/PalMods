# BetterPalSouls — 更好的帕鲁魂强化

版本 **0.2.6 experimental**，强化提交及保存同步仍需游戏内验收。

0.2.6 原版加减在蓝图执行完毕后读取目标等级，避免预执行钩子读取旧值；记录最大选择、协调后目标及提交前后预算，排查确认后同一项仍可提高的问题。

0.2.5 解包原版费用 Map 中键和值的 RemoteUnrealParam，修正物品键直接调用 ToString 失败。

0.2.4 修正原版费用接口返回的 `RequiredItems` 外层表解析，避免提交在魂转换之前误报 native_cost_unsupported。

0.2.3 卸载时显式注销本 Mod 的蓝图回调，避免与其他 Mod 共用按钮事件时残留已关闭 Lua 状态的引用。更新后请完整退出并重新启动游戏，避免对旧版本热重载。

0.2.2 去除新增按钮及强化按钮的 tooltip。

0.2.1 隐藏透明点击层的禁用背景，保留外层图标／文字和真正的禁用状态，
修正禁用按钮变成白块及双箭头竖向对齐的问题。

保留力量石像的原版强化界面：属性名称、百分比、格子条、单次加减和四种魂的费用显示。
在加减内侧增加粗实心单箭头，顺序为 `− ◀ 百分比 ▶ +`，箭头使用与加减一致的方形背景。
保留原版加减按钮的位置与格子条尺寸，箭头放在加减与百分比之间，不再使用工作台选择器。

- `◀`：回到该属性当前已强化等级，取消该项待强化选择；不会退还已花费的魂或重置属性。
- 原版 `− / +`：单次减少／增加一级。
- `▶`：选择剩余帕鲁魂预算允许的最高等级，保留其他三项的预算，不是增加十级。

四项属性共享库存预算。目标等级同步到原版 `TargetStatusRankMap`，费用完全由原版
`UpdateRequiredItemSufficiency` 统一计算和显示，不创建独立费用控件、不直接写费用数字。
原版单次加减已经刷新费用时，Mod 不重复计算显示。空闲检查状态不变时不重绘。
重置页面继续使用原版界面，隐藏箭头并恢复格子条尺寸。

小型、中型、大型、究极帕鲁魂按原版相邻两级 2:1 自动合并／拆分。
优先使用已有对应大小的魂，只转换缺口并返还余数。预览不扣魂；点击强化时重新读取
库存和等级，核对原版累计消耗，转换，然后执行原版强化请求。
强化效果、等级上限和消耗使用当前游戏数据。

库存范围是玩家背包和当前基地中原版强化界面允许使用的容器。
未知或不一致的库存范围拒绝转换。新魂放入背包空位或原有同类槽，
不替换其他物品。临时转换需要的空位不足时，请先腾出背包空位。

目前仅支持**单人及联机房主本机**。远程客户端及专用服务器协议未实现。
转换直接更新本机权威魂槽并发送槽更新通知；原版请求返回后检查强化等级和剩余数量。
失败时尝试恢复操作前的魂槽和强化等级，并禁用本次运行的后续自动强化。
此实现依赖房主请求在当前线程内完成；库存缓存、保存同步和恢复仍需实机验收。

## 构建和安装

```powershell
python mods/BetterPalSouls/tests/run.py
python tools/build.py BetterPalSouls
```

生成 `dist/BetterPalSouls/BetterPalSouls-0.2.6-experimental.zip`，构建不会安装到游戏。
0.2.0 是 Lua Mod，不需要自定义界面 PAK、UAssetGUI 或游戏映射。

游戏退出后，将 ZIP 中的 `Mods/` 合并到 Palworld 安装目录。
需要已启用 UE4SS Lua Mod，操作实验包前备份存档。
安装位置：`Mods/NativeMods/UE4SS/Mods/BetterPalSouls/`。

从 0.1.x 升级时，旧版 `Pal/Content/Paks/~mods/BetterPalSouls_UI_P.pak` 已不再使用，
可在游戏退出后删除。卸载时删除 Mod 目录，并删除 `mods.txt` 中的 BetterPalSouls 条目。
已完成的强化和剩余魂都是原版数据。

`Scripts/config.lua` 支持 `Enabled`、`Language`、`RefreshIntervalMs`。
语言可用 `auto`、`zh-Hans`、`zh-Hant`、`en`、`ja`。

待实机验收：最小／最大箭头、原版单次加减、四行共享预算、魂合并／拆分与找零、
基地库存、背包满时拒绝、提交失败恢复、切换帕鲁与重置页、手柄焦点、保存后重载。
