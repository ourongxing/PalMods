# Better Pal Souls / パルソウル強化の改善

1.0.0 · ourongxing

必要な種類のパルソウルが足りなくても、強化時に自動変換。手持ちで届く最高レベルもワンクリックで選べます。

## 使い方

力の石像でパルの強化画面を開きます。

- **▶ 最大を選択**：ほかの項目で選択済みの強化に必要な分を残し、その項目で選べる最高レベルを指定します。
- **◀**：その項目の未確定の強化を取り消します。
- **− / + 1段階ずつ調整**：標準ボタンもそのまま使えます。選び終えたら強化を確定してください。

## ソウルの自動変換

4種類のソウルを小さい順に **1 / 2 / 4 / 8** で換算します。プレビューでは在庫を変更せず、強化確定時に必要な種類へ変換し、余りはすべて小さいパルソウルで残します。

バッグと、現在の拠点で標準強化画面が利用できる収納を使用します。変換にはバッグの空き枠が必要な場合があります。強化効果、上限、費用はゲーム設定に従います。

## 導入方法

1. 必要な Mod（UE4SSExperimentalPW）をサブスクライブして有効にします。
2. ゲーム内の Mod 管理で本 Mod を有効にします。
3. ゲームを完全に終了してから、再起動してください。

## 設定

Palworld のインストール先にある `Mods/NativeMods/UE4SS/Mods/BetterPalSouls/Scripts/config.lua` を編集し、保存後にゲームを完全に終了して再起動してください。

## 利用上の注意

シングルプレイと協力プレイのホスト本人のみ対応しています。参加プレイヤーと専用サーバーには対応していません。

強化の確定、保存・読み込み、操作失敗時の復元、コントローラー操作はゲーム内での検証が完了していません。初回使用前にセーブをバックアップしてください。
