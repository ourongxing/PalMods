# パルソウル強化の改善

1.0.0 · ourongxing

力の石像の標準強化画面で強化レベルを素早く選び、確定した強化に必要なパルソウルを自動で変換します。

標準のステータス、レベル表示、1段階ずつの増減ボタン、必要数の表示を維持し、パーセント表示の両側に矢印を追加します。◀ はその項目の未確定の強化選択を取り消し、現在の強化レベルに戻します。ステータスのリセットや使用済みソウルの返却は行いません。▶ は他の項目に割り当てたソウルを確保したうえで、残りのソウルで選択できる最高レベルを選びます。4項目で同じ在庫予算を共有し、標準の − / + で1段階ずつ調整できます。

4種類のパルソウルを、小さいものから順に 1 / 2 / 4 / 8 の比率で換算します。プレビューでは在庫を変更しません。強化を確定すると必要なソウルに変換し、残りはすべて小さいパルソウルとして保持します。強化効果、上限、消費数は現在のゲームデータに従います。プレイヤーのバッグと、現在の拠点で標準強化画面が利用できる収納を使用します。変換に必要な空き枠が足りない場合は、バッグに空きを作ってください。リセット画面は標準の動作を維持します。

設定ファイル：`Scripts/config.lua`。`Enabled` で有効・無効を切り替えます。`Language` は既定の `auto` でゲームの言語に従い、`zh-Hans`、`zh-Hant`、`ja`、`en` も指定できます。

現在はシングルプレイと協力プレイのホスト本人に対応しています。リモートクライアントと専用サーバーには対応していません。強化の確定、セーブの同期、失敗時の復元、コントローラー操作はゲーム内での検証が必要です。初回使用前にセーブをバックアップしてください。

依存 mod の UE4SSExperimentalPW をサブスクライブして有効にしてください。その後、ゲームの mod 管理で本 mod を有効にし、ゲームを完全に終了して再起動してください。
