# Better Pal Souls / パルソウル強化の改善

1.0.0 · ourongxing

力の石像の標準強化画面で強化レベルを素早く選び、今回の強化に必要なパルソウルを自動で変換します。

## 機能と使い方

- ◀：その項目の未確定の強化選択を取り消し、現在の強化レベルに戻します。能力のリセットや使用済みソウルの返却は行いません。
- ▶：ほかの項目で選択済みの強化に必要な分を残し、残りのソウルで選べる最高レベルを指定します。
- 標準の − / +：1 段階ずつ調整します。4 項目で使えるソウルを共有し、必要数は標準の画面に表示されます。

4 種類のパルソウルを小さいものから順に 1 / 2 / 4 / 8 の比率で換算します。プレビューでは在庫を変更しません。強化を確定すると必要な種類に変換し、余りはすべて小さいパルソウルとして残します。

プレイヤーのバッグと、現在の拠点で標準強化画面が利用できる収納を使用します。変換用の空き枠が足りない場合は、バッグに空きを作ってください。強化効果、上限、消費数はゲームの設定に従い、リセット画面も通常どおり使えます。

## 導入方法

1. 必要な Mod（UE4SSExperimentalPW）をサブスクライブして有効にします。
2. ゲーム内の Mod 管理で本 Mod を有効にします。
3. ゲームを完全に終了してから、再起動してください。

## 設定

Palworld のインストール先にある `Mods/NativeMods/UE4SS/Mods/BetterPalSouls/Scripts/config.lua` を編集し、保存後にゲームを完全に終了して再起動してください。

- `Enabled`：機能の有効・無効。
- `Language`：初期値の `auto` でゲームの言語に合わせます。`zh-Hans`、`zh-Hant`、`ja`、`en` も指定できます。

## 利用上の注意

シングルプレイと協力プレイのホスト本人のみ対応しています。参加プレイヤーと専用サーバーには対応していません。

強化の確定、保存・読み込み、操作失敗時の復元、コントローラー操作はゲーム内での検証が完了していません。初回使用前にセーブをバックアップしてください。
