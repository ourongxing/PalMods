# 更好的帕鲁魂强化

1.0.0 · ourongxing

在力量石像的原版强化界面快速选择强化等级，并自动兑换本次强化所需的帕鲁魂。

保留原版属性、格子条、单次加减和费用显示，在百分比两侧增加箭头。◀ 取消该属性尚未提交的强化选择，回到当前已强化等级；不会重置属性或退还已花费的魂。▶ 选择剩余帕鲁魂预算允许的最高等级，并保留其他属性的预算。四项属性共享库存预算，原版 − / + 仍可逐级调整。

小型、中型、大型、究极帕鲁魂按 1 / 2 / 4 / 8 统一换算。预览不改变库存；点击强化时自动兑换所需魂，剩余全部保留为小型魂。强化效果、等级上限和消耗沿用当前游戏数据。使用玩家背包和当前基地中原版强化界面允许使用的容器；转换所需空位不足时，请先腾出背包空位。重置页面沿用原版功能。

配置文件：`Scripts/config.lua`。`Enabled` 控制启用，`Language` 默认为 `auto`，跟随游戏语言，也可设为 `zh-Hans`、`zh-Hant`、`ja` 或 `en`。

目前支持单人及联机房主本机，不支持远程客户端或专用服务器。强化提交、保存同步、失败恢复和手柄操作仍需游戏内验收。首次使用前请备份存档。

先订阅并启用依赖：UE4SSExperimentalPW。然后在游戏的 mod 管理中启用本 mod，并完整退出、重新启动游戏。
