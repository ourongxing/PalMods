# Better Pal Souls / 更好的帕鲁魂强化

1.0.0 · ourongxing

帕鲁魂种类不够？强化时自动兑换，还能一键选到当前能负担的最高等级。

## 怎么用

打开力量石像的帕鲁强化界面：

- **▶ 选到最高**：用剩余帕鲁魂选择该属性能达到的最高等级，并为其他属性已选的强化保留用量。
- **◀**：取消该属性的待强化选择。
- **− / + 逐级调整**：原版按钮照常使用，选好后点击强化确认。

## 自动兑换帕鲁魂

小型／中型／大型／究极魂按 **1／2／4／8** 换算。预览不改库存，确认强化时自动兑换所需种类，余量全部保留为小型魂。

使用背包及当前据点中原版强化界面可用的库存。兑换可能需要背包空位；强化效果、上限和费用沿用游戏设置。

## 安装

1. 订阅并启用前置 Mod：UE4SSExperimentalPW。
2. 在游戏的 Mod 管理中启用本 Mod。
3. 完全退出游戏，再重新启动。

## 配置

在 Palworld 安装目录中编辑 `Mods/NativeMods/UE4SS/Mods/BetterPalSouls/Scripts/config.lua`，保存后完全退出并重启游戏。

## 使用须知

仅支持单人游戏和联机房主本人，不支持加入他人房间的玩家或专用服务器。

强化确认、保存与重新读取、操作失败后的恢复、手柄操作尚未完成游戏内验证。首次使用前请备份存档。
