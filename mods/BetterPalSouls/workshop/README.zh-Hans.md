# Better Pal Souls / 更好的帕鲁魂强化

1.0.0 · ourongxing

在力量石像的原版强化界面快速选择强化等级，并自动兑换本次强化需要的帕鲁魂。

## 功能与使用

- ◀：取消该属性尚未确认的强化选择，回到当前已强化等级；不会重置属性或退还已花费的魂。
- ▶：选择剩余魂数量允许的最高等级，同时为其他属性已选的强化保留用量。
- 原版 − / +：逐级调整。四项属性共享可用帕鲁魂，费用仍显示在原版界面中。

小型、中型、大型、究极帕鲁魂按 1 / 2 / 4 / 8 换算。预览不改变库存；确认强化时自动兑换所需魂，余量全部保留为小型魂。

可使用玩家背包和当前据点中原版强化界面允许使用的容器。转换需要背包空位，空间不足时请先腾出空位。强化效果、等级上限和消耗沿用游戏设置，重置页面照常使用。

## 安装

1. 订阅并启用前置 Mod：UE4SSExperimentalPW。
2. 在游戏的 Mod 管理中启用本 Mod。
3. 完全退出游戏，再重新启动。

## 配置

在 Palworld 安装目录中编辑 `Mods/NativeMods/UE4SS/Mods/BetterPalSouls/Scripts/config.lua`，保存后完全退出并重启游戏。

- `Enabled`：开启或关闭功能。
- `Language`：默认 `auto`，跟随游戏语言；也可指定 `zh-Hans`、`zh-Hant`、`ja` 或 `en`。

## 使用须知

仅支持单人游戏和联机房主本人，不支持加入他人房间的玩家或专用服务器。

强化确认、保存与重新读取、操作失败后的恢复、手柄操作尚未完成游戏内验证。首次使用前请备份存档。
