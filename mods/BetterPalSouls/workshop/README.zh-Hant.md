# 更好的帕魯魂強化

1.0.0 · ourongxing

在力量石像的原版強化介面快速選擇強化等級，並自動兌換本次強化所需的帕魯魂。

保留原版屬性、格子條、單次加減和費用顯示，在百分比兩側增加箭頭。◀ 取消該屬性尚未提交的強化選擇，回到目前已強化等級；不會重置屬性或退還已花費的魂。▶ 選擇剩餘帕魯魂預算允許的最高等級，並保留其他屬性的預算。四項屬性共用庫存預算，原版 − / + 仍可逐級調整。

小型、中型、大型、究極帕魯魂按 1 / 2 / 4 / 8 統一換算。預覽不改變庫存；點擊強化時自動兌換所需魂，剩餘全部保留為小型魂。強化效果、等級上限和消耗沿用目前遊戲資料。使用玩家背包和目前據點中原版強化介面允許使用的容器；轉換所需空位不足時，請先騰出背包空位。重置頁面沿用原版功能。

設定檔：`Scripts/config.lua`。`Enabled` 控制啟用，`Language` 預設為 `auto`，跟隨遊戲語言，也可設為 `zh-Hans`、`zh-Hant`、`ja` 或 `en`。

目前支援單人及連線房主本機，不支援遠端客戶端或專用伺服器。強化提交、存檔同步、失敗復原和控制器操作仍需遊戲內驗收。首次使用前請備份存檔。

先訂閱並啟用相依模組：UE4SSExperimentalPW。然後在遊戲的 mod 管理中啟用本 mod，並完整結束、重新啟動遊戲。
