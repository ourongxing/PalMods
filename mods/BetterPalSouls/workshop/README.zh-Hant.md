# Better Pal Souls / 更好的帕魯魂強化

1.0.0 · ourongxing

帕魯魂種類不夠？強化時自動兌換，還能一鍵選到目前能負擔的最高等級。

## 怎麼用

開啟力量石像的帕魯強化介面：

- **▶ 選到最高**：用剩餘帕魯魂選擇該屬性能達到的最高等級，並為其他屬性已選的強化保留用量。
- **◀**：取消該屬性的待強化選擇。
- **− / + 逐級調整**：原版按鈕照常使用，選好後點選強化確認。

## 自動兌換帕魯魂

小型／中型／大型／究極魂依 **1／2／4／8** 換算。預覽不改庫存，確認強化時自動兌換所需種類，餘量全部保留為小型魂。

使用背包及目前據點中原版強化介面可用的庫存。兌換可能需要背包空位；強化效果、上限與費用沿用遊戲設定。

## 安裝

1. 訂閱並啟用前置 Mod：UE4SSExperimentalPW。
2. 在遊戲的 Mod 管理中啟用本 Mod。
3. 完全退出遊戲，再重新啟動。

## 設定

在 Palworld 安裝目錄中編輯 `Mods/NativeMods/UE4SS/Mods/BetterPalSouls/Scripts/config.lua`，儲存後完全退出並重新啟動遊戲。

## 使用須知

僅支援單人遊戲與連線房主本人，不支援加入他人房間的玩家或專用伺服器。

強化確認、儲存與重新讀取、操作失敗後的還原、控制器操作尚未完成遊戲內驗證。首次使用前請備份存檔。
