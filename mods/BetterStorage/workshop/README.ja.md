# より便利な収納

1.1.0 · ourongxing

標準の「一括便利収納」を拠点の外でも使えるようにし、スタック上限の引き上げ、設計図専用家具の大容量化、ギルド共有倉庫の容量設定を追加します。

拠点内では現在の拠点へ、拠点外では所属ギルドで建築物が最も多い拠点へ収納します。建築数が同じ場合は、プレイヤーに最も近い拠点を選びます。インベントリを開き、標準の「一括便利収納」ボタンまたはショートカットを使ってください（キーボードの初期設定は R）。

収納可否のグレー表示、除外リスト、確認画面は標準のままです。チェストのカテゴリ、アクセス権限、容量制限に従います。収納先には同じ種類のアイテムが既に入っている必要があり、空のチェストや別の種類しか入っていないチェストへ新しい種類を追加しません。

通常のスタック可能なアイテムは、インベントリ、チェスト、生産用ストレージで共通して、1スタックの上限が最低 99,999 になります。標準の上限がそれ以上の場合は維持され、金貨の上限も 99,999,999 のままです。スタック不可のアイテムや個別インスタンスを持つアイテムは標準のルールを維持します。既存のスタックを自動でまとめる機能はありません。アンインストール前に、標準上限を超えたスタックを分割してください。

パルの運搬では、同じ運搬優先度の中で、上限に達していない同種のスタックがあるチェストを優先します。既存のカテゴリ、権限、優先度は引き続き有効です。

アンティーク調の本棚と大型キャビネット（Shelf01_Stone、Shelf07_Stone）を、設計図専用の360スロットに変更します。既に設置している家具には、解体・再建築が必要です。

新規作成されるギルド共有倉庫の初期容量は360スロットです。すべてのギルドチェストは引き続き同じ倉庫を共有します。既存の共有倉庫は拡張されず、ギルドチェストを作り直しても旧倉庫の容量は変わりません。360スロット家具の標準画面は、表示負荷が高くなる場合があります。

容量設定：UE4SS/Mods/PalSchema/mods/BetterStorage/blueprints/storage.json。家具ごとの SlotNum とギルドの GuildChestSlotNum を個別に変更できます。変更後はゲームまたはサーバーを完全に再起動してください。それ以降に作成される対象のコンテナまたはギルド共有倉庫にのみ適用されます。

UE4SSExperimentalPW と PalSchema をサブスクライブして有効にし、ゲーム内のMOD管理で本MODを有効にした後、ゲームを完全に終了して再起動してください。BetterBulkStorage との同時使用はできません。

ローカルのシングルプレイで拠点外収納とグレー表示を確認済みで、収納処理の最適化にも改善の報告があります。マルチプレイは未検証です。スタック上限、運搬、容量の変更にはホストまたはサーバーへの導入が必要で、クライアントだけではサーバーのルールを変更できません。新規ギルド共有倉庫の容量と同期は、引き続き実機確認が必要です。
