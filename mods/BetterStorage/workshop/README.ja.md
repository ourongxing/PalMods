# Better Storage / より便利な収納

1.2.0 · ourongxing

拠点の外からアイテムを収納し、スタック上限を増やしてバッグやチェストの枠を節約します。

## 主な機能

- **拠点外から収納**：インベントリで R（初期設定）を押すと、メイン拠点へ収納します。拠点内では現在の拠点を使用します。メイン拠点はギルドの建築物が最も多い拠点で、同数なら最寄りを選びます。
- **スタック上限アップ**：通常のスタック可能アイテムは1枠あたり最低 99,999 個。それ以上の上限や、装備などのスタック不可アイテムは変更しません。
- **パルの運搬を改善**：同じ運搬優先度なら、同種のスタックに空きがあるチェストを優先します。
- **設計図専用収納**：アンティーク調の本棚と大型キャビネットを設計図専用の 360 枠にします。設置済みの家具は再建築が必要です。
- **ギルド共有倉庫を拡張**：新しく作成する共有倉庫を 360 枠にします。既存の倉庫は拡張されず、チェストの再建築でも変わりません。

一括収納は同じ種類のアイテムが既に入っているチェストだけを使用します。標準のカテゴリー、権限、除外リスト、確認画面はそのままです。

## 導入方法

1. 必要な Mod（UE4SSExperimentalPW, PalSchema）をサブスクライブして有効にします。
2. ゲーム内の Mod 管理で本 Mod を有効にします。
3. ゲームを完全に終了してから、再起動してください。

## 設定

Palworld のインストール先にある `Mods/NativeMods/UE4SS/Mods/PalSchema/mods/BetterStorage/blueprints/storage.json` を編集し、保存後にゲームを完全に終了して再起動してください。

ファイル内の 2 か所の `SlotNum` は本棚とキャビネットのスロット数、`GuildChestSlotNum` は新しいギルド共有倉庫のスロット数です。

## 利用上の注意

Windows 専用サーバー用の独立 DLL を同梱しています。サーバーとクライアントの両方に本 Mod と前提 Mod を導入してください。
