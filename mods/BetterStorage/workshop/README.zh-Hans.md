# Better Storage / 更好的收纳

1.2.0 · ourongxing

在野外也能一键收纳回据点，让背包和箱子少占几格。

## 主要功能

- **野外收纳**：打开背包按 R（默认键），将物品收回主据点；据点内仍收纳到当前据点。主据点按公会建筑数量选择，同数量取最近。
- **更大堆叠**：普通可堆叠物品每格至少可放 99,999 个，原本更高的上限不降低。装备等不可堆叠物品保持原样。
- **搬运优先叠放**：同一搬运优先级下，帕鲁优先把物品放进已有同类且未满的箱子。
- **设计图专用收纳**：古典书架和古典大型橱柜改为 360 格，只收设计图；已建家具需要重建。
- **公会库存扩容**：新创建的公会库存为 360 格，各公会箱子共享。旧库存不会扩容，重建箱子也无效。

快速收纳只存入已有同类物品的箱子，保留原版分类、权限、排除列表和确认窗口。

## 安装

1. 订阅并启用前置 Mod：UE4SSExperimentalPW, PalSchema。
2. 在游戏的 Mod 管理中启用本 Mod。
3. 完全退出游戏，再重新启动。

## 配置

在 Palworld 安装目录中编辑 `Mods/NativeMods/UE4SS/Mods/PalSchema/mods/BetterStorage/blueprints/storage.json`，保存后完全退出并重启游戏。

文件内的两处 `SlotNum` 分别设置书架和橱柜格数，`GuildChestSlotNum` 设置新公会库存格数。

## 使用须知

包含独立的 Windows 专用服务器 DLL。服务器和客户端均需安装本模组及前置依赖。
