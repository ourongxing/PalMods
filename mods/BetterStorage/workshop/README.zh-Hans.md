# Better Storage / 更好的收纳

1.1.0 · ourongxing

在野外使用原版“批量快速收纳”，提高堆叠上限，优化帕鲁搬运，并增加设计图专用大容量家具与公会库存容量设置。

## 功能与使用

打开背包，使用原版“批量快速收纳”按钮或快捷键（键盘默认 R）。

- 收纳目的地：据点内收纳到当前据点；野外收纳到所属公会建筑物最多的主据点，建筑数相同时选择距离玩家最近的据点。
- 原版收纳规则：目标箱子必须已有同类物品，不会把新种类放入空箱或只有其他物品的箱子。保留可收纳物品提示、除外项目表和确认窗口，遵守分类、权限和容量限制。
- 堆叠上限：背包、箱子和生产库存中的普通可堆叠物品，单格上限至少为 99,999；原版更高上限保持不变，金币仍为 99,999,999。装备等不可按普通方式堆叠的物品沿用原规则。
- 帕鲁搬运：相同搬运优先级内，优先选择已有未满同类堆叠的箱子；原有箱子分类、权限与优先级继续生效。
- 设计图家具：古典书架和古典大型橱柜改为 360 格，仅存放设计图。已建造的家具需要拆除重建，才能应用容量与分类设置。
- 公会库存：新创建的公会库存默认为 360 格，所有公会箱子仍共享同一份库存。已有公会库存不会扩容，拆除重建公会箱子也不会改变旧库存容量。

## 安装

1. 订阅并启用前置 Mod：UE4SSExperimentalPW, PalSchema。
2. 在游戏的 Mod 管理中启用本 Mod。
3. 完全退出游戏，再重新启动。

## 配置

在 Palworld 安装目录中编辑 `Mods/NativeMods/UE4SS/Mods/PalSchema/mods/BetterStorage/blueprints/storage.json`，保存后完全退出并重启游戏。

文件内的两处 `SlotNum` 分别设置书架和橱柜格数，`GuildChestSlotNum` 设置新公会库存格数。

修改后完全退出并重启游戏或服务器，仅影响之后创建的对应家具或公会库存。

## 使用须知

已在单人游戏中测试野外收纳和物品提示。多人游戏尚未验证，堆叠、搬运和容量修改需要主机或服务器安装，仅在加入服务器的玩家电脑上安装无法改变服务器规则。新公会库存容量与多人同步尚未完成验证。

不要与 BetterBulkStorage 同时启用。360 格家具界面可能降低帧率，可适当调低新家具的容量。

不会自动合并已有的分散堆叠。卸载前请将超过原版上限的堆叠拆分。
