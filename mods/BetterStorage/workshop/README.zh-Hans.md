# 更好的收纳

1.0.0 · ourongxing

扩展原版“批量快速收纳”的使用范围，提升堆叠上限，并增加设计图专用大容量家具与公会库存容量设置。

在据点内，收纳到当前据点；在野外，收纳到所属公会建筑物最多的主据点，建筑数量相同时选择距离玩家最近的据点。打开背包，使用原版“批量快速收纳”按钮或快捷键即可（键盘默认 R）。

沿用原版可收纳物品灰显、除外项目表和确认窗口，遵守箱子的分类、权限与容量限制。目标箱子必须已有同类物品；不会把新种类放入空箱或只有其他物品的箱子。

普通可堆叠物品的单格上限至少为 99,999，背包、箱子和生产库存共用。原版更高上限保持不变，金币保留 99,999,999 上限；不可堆叠物品和独立实例物品沿用原版规则。不会自动合并已有分散堆叠。卸载前请将超出原版上限的堆叠拆分。

帕鲁搬运时，在相同搬运优先级内优先选择有未满同类堆叠的箱子；箱子的原有分类、权限与优先级仍生效。

古典书架与古典大型橱柜（Shelf01_Stone、Shelf07_Stone）改为 360 格，仅存放设计图。已建造的这两种家具需要拆除重建才能应用容量与过滤设置。

新创建的公会库存默认为 360 格，所有公会箱子仍共享同一个库存。已有公会库存不会扩容，拆除重建公会箱子也不能改变旧库存容量。360 格家具的原版界面可能有较高开销。

容量配置位于 UE4SS/Mods/PalSchema/mods/BetterStorage/blueprints/storage.json。两个家具的 SlotNum 与公会的 GuildChestSlotNum 可分别调整，修改后完全退出并重启游戏或服务器；仅影响此后创建的对应容器或公会库存。

先订阅并启用 UE4SSExperimentalPW 和 PalSchema，再在游戏模组管理中启用本模组，完全退出游戏并重启。不要与 BetterBulkStorage 同时启用。

本机单人游戏已测试野外收纳与灰显，并反馈快速收纳优化有效。多人游戏尚未验证：堆叠上限、搬运与容量补丁需要主机或服务器加载，不能仅靠客户端安装改变服务器规则；新公会库存容量与同步仍需实机验证。
