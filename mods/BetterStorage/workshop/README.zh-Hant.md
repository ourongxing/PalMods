# 更好的收納

1.1.0 · ourongxing

在野外使用原版「批量快速收納」，提高堆疊上限，改善帕魯搬運，並增加設計圖專用大容量家具與公會庫存容量設定。

## 功能與使用

開啟背包，使用原版「批量快速收納」按鈕或快捷鍵（鍵盤預設 R）。

- 收納目的地：據點內收納至目前據點；野外收納至所屬公會建築物最多的主據點，建築數相同時選擇距離玩家最近的據點。
- 原版收納規則：目標箱子必須已有同類物品，不會把新種類放入空箱或只有其他物品的箱子。保留可收納物品提示、除外項目表與確認視窗，遵守分類、權限及容量限制。
- 堆疊上限：背包、箱子與生產庫存中的普通可堆疊物品，單格上限至少為 99,999；原版更高上限維持不變，金幣仍為 99,999,999。裝備等無法以普通方式堆疊的物品沿用原規則。
- 帕魯搬運：相同搬運優先級內，優先選擇已有未滿同類堆疊的箱子；原有箱子分類、權限與優先級繼續生效。
- 設計圖家具：古典書架與古典大型櫥櫃改為 360 格，僅存放設計圖。已建造的家具需要拆除重建，才能套用容量與分類設定。
- 公會庫存：新建立的公會庫存預設為 360 格，所有公會箱子仍共用同一份庫存。既有公會庫存不會擴容，拆除重建公會箱子也不會改變舊庫存容量。

## 安裝

1. 訂閱並啟用前置 Mod：UE4SSExperimentalPW, PalSchema。
2. 在遊戲的 Mod 管理中啟用本 Mod。
3. 完全退出遊戲，再重新啟動。

## 設定

在 Palworld 安裝目錄中編輯 `Mods/NativeMods/UE4SS/Mods/PalSchema/mods/BetterStorage/blueprints/storage.json`，儲存後完全退出並重新啟動遊戲。

檔案中的兩處 `SlotNum` 分別設定書架與櫥櫃格數，`GuildChestSlotNum` 設定新公會庫存格數。

修改後完全退出並重新啟動遊戲或伺服器，僅影響之後建立的對應家具或公會庫存。

## 使用須知

已在單人遊戲中測試野外收納與物品提示。多人遊戲尚未驗證，堆疊、搬運與容量修改需要主機或伺服器安裝，僅在加入伺服器的玩家電腦上安裝無法改變伺服器規則。新公會庫存容量與多人同步尚未完成驗證。

請勿與 BetterBulkStorage 同時啟用。360 格家具介面可能降低幀率，可適度調低新家具的容量。

不會自動合併既有的分散堆疊。解除安裝前請將超過原版上限的堆疊拆分。

## 問題回報

請到 GitHub Issues 回報問題：https://github.com/ourongxing/PalMods/issues

沒有 UE4SS 日誌，我無法定位並修復 Bug。

請提供以下資訊，方便查明原因：

- Mod 名稱、遊戲與 Mod 版本、遊戲語言。
- 單人遊戲、連線房主、加入他人房間或專用伺服器。
- 重現步驟、預期與實際情況，以及相關截圖和已啟用的其他 Mod。
- 發生問題後的完整 `UE4SS.log` 檔案，請以附件上傳。

在 Steam 中以右鍵點選 Palworld → 管理 → 瀏覽本機檔案，然後開啟 `Mods\NativeMods\UE4SS\UE4SS.log`。
例如，遊戲安裝在 G 槽時，完整路徑為：
`G:\SteamLibrary\steamapps\common\Palworld\Mods\NativeMods\UE4SS\UE4SS.log`

磁碟代號和 Steam 收藏庫目錄請依實際安裝位置調整。請在再次啟動遊戲前複製日誌，避免本次問題的紀錄被覆蓋。
