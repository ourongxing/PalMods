# 更好的收納

1.0.0 · ourongxing

擴展原版「批量快速收納」的使用範圍，提高堆疊上限，並增加設計圖專用大容量家具與公會庫存容量設定。

在據點內，收納到目前據點；在野外，收納到所屬公會建築物最多的主據點，建築數量相同時選擇距離玩家最近的據點。開啟背包，使用原版「批量快速收納」按鈕或快捷鍵即可（鍵盤預設 R）。

沿用原版可收納物品灰顯、除外項目表和確認視窗，遵守箱子的分類、權限與容量限制。目標箱子必須已有同類物品；不會把新種類放入空箱或只有其他物品的箱子。

普通可堆疊物品的單格上限至少為 99,999，背包、箱子和生產庫存共用。原版更高上限保持不變，金幣保留 99,999,999 上限；不可堆疊物品和獨立實例物品沿用原版規則。不會自動合併既有分散堆疊。解除安裝前請將超出原版上限的堆疊拆分。

帕魯搬運時，在相同搬運優先級內優先選擇有未滿同類堆疊的箱子；箱子原有的分類、權限與優先級仍生效。

古典書架與古典大型櫥櫃（Shelf01_Stone、Shelf07_Stone）改為 360 格，僅存放設計圖。已建造的這兩種家具需要拆除重建才能套用容量與過濾設定。

新建立的公會庫存預設為 360 格，所有公會箱子仍共用同一個庫存。既有公會庫存不會擴容，拆除重建公會箱子也不能改變舊庫存容量。360 格家具的原版介面可能有較高開銷。

容量設定位於 UE4SS/Mods/PalSchema/mods/BetterStorage/blueprints/storage.json。兩種家具的 SlotNum 與公會的 GuildChestSlotNum 可分別調整，修改後完全退出並重新啟動遊戲或伺服器；僅影響此後建立的對應容器或公會庫存。

先訂閱並啟用 UE4SSExperimentalPW 和 PalSchema，再於遊戲模組管理中啟用本模組，完全退出遊戲並重新啟動。請勿與 BetterBulkStorage 同時啟用。

本機單人遊戲已測試野外收納與灰顯，並回報快速收納最佳化有效。多人遊戲尚未驗證：堆疊上限、搬運與容量補丁需要主機或伺服器載入，不能僅靠客戶端安裝改變伺服器規則；新公會庫存容量與同步仍需實機驗證。
