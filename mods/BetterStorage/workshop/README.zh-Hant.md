# Better Storage / 更好的收納

1.1.0 · ourongxing

在野外也能一鍵收納回據點，讓背包和箱子少佔幾格。

## 主要功能

- **野外收納**：開啟背包按 R（預設鍵），將物品收回主據點；據點內仍收納至目前據點。主據點依公會建築數量選擇，同數量取最近。
- **更大堆疊**：一般可堆疊道具每格至少可放 99,999 個，原本更高的上限不降低。裝備等不可堆疊道具維持原樣。
- **搬運優先堆疊**：相同搬運優先級下，帕魯優先將道具放進已有同類且未滿的箱子。
- **設計圖專用收納**：古典書架和古典大型櫥櫃改為 360 格，只收設計圖；已建家具需要重建。
- **公會庫存擴容**：新建立的公會庫存為 360 格，各公會箱子共用。舊庫存不會擴容，重建箱子也無效。

快速收納只存入已有同類道具的箱子，保留原版分類、權限、排除清單與確認視窗。

## 安裝

1. 訂閱並啟用前置 Mod：UE4SSExperimentalPW, PalSchema。
2. 在遊戲的 Mod 管理中啟用本 Mod。
3. 完全退出遊戲，再重新啟動。

## 設定

在 Palworld 安裝目錄中編輯 `Mods/NativeMods/UE4SS/Mods/PalSchema/mods/BetterStorage/blueprints/storage.json`，儲存後完全退出並重新啟動遊戲。

檔案中的兩處 `SlotNum` 分別設定書架與櫥櫃格數，`GuildChestSlotNum` 設定新公會庫存格數。

## 使用須知

已在單人遊戲中測試野外收納與物品提示。多人遊戲尚未驗證，堆疊、搬運與容量修改需要主機或伺服器安裝，僅在加入伺服器的玩家電腦上安裝無法改變伺服器規則。新公會庫存容量與多人同步尚未完成驗證。

請勿與 BetterBulkStorage 同時啟用。360 格家具介面可能降低幀率，可適度調低新家具的容量。

不會自動合併既有的分散堆疊。解除安裝前請將超過原版上限的堆疊拆分。
