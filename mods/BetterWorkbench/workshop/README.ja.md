# 作業台の機能拡張

1.0.0 · ourongxing

同じ作業台で作れる中間素材が足りないとき、その素材に必要な材料まで自動で計算します。素材一覧のスクロールと即時分解にも対応しています。

手持ちの中間素材を優先して使い、不足分だけを、その作業台で解放済みのレシピに従って補います。レシピ詳細に表示される完成品の所持数を選ぶと、分解モードに切り替わります。回数を指定して確定すると、レシピ1回分ごとに完成品を消費し、元の素材をすべてインベントリに返却します。

設定ファイル：`Scripts/config.lua`。`Disassembly.Language` の初期値は `auto` で、ゲームの言語に合わせて表示します。`zh-Hans`、`zh-Hant`、`ja`、`en` で言語を指定することもできます。アイテム名はゲーム内の表記を使用します。

分解はシングルプレイとマルチプレイのホスト側で対応しています。マルチプレイでの制作タスク定義の同期は未実装です。アイテムの消費、コントローラー操作、素材の返却、セーブ後の復元はゲーム内での検証が必要です。未完了タスクの `Jobs/*.bwj` はセーブデータと一緒に保管してください。

必要なmod（UE4SSExperimentalPW）をサブスクライブして有効にしてください。その後、ゲームのmod管理でこのmodを有効にし、ゲームを再起動してください。
