# Better Workbench / 更好的工作台

1.1.0 · ourongxing

> 新增专用服务器支持，修复分解问题和崩溃。

---

少做几步中间材料，用不上的成品也能拆回原料。

## 主要功能

- **直接用原料制作**：缺少中间材料时，自动用原料补足，优先消耗已有的中间材料。仅限当前工作台已解锁的配方，不能跨工作台制作。
- **材料列表可滚动**：默认显示 5 行，鼠标滚轮查看其余材料。
- **即时分解**：成品按完整配方批次分解，原配方材料全额返还背包。
- **Windows 专用服务器**：支持多人制作任务同步，分解由服务器校验并结算。

## 怎么用

照常选择配方并制作即可。点击配方详情右上角的**成品持有数量**，可切换制作／分解，再选择批数并确认。

单次最多制作或分解 256 批。工时按所选成品配方计算，不额外计入中间材料的制作时间。

## 安装

1. 订阅并启用前置 Mod：UE4SSExperimentalPW。
2. 在游戏的 Mod 管理中启用本 Mod。
3. 完全退出游戏，再重新启动。

游玩专用服务器时，Windows 服务器与每位玩家的客户端都需要安装相同版本的本 Mod 和 UE4SSExperimentalPW，安装后重启两端。

## 配置

在 Palworld 安装目录中编辑 `Mods/NativeMods/UE4SS/Mods/BetterWorkbench/Scripts/config.lua`，保存后完全退出并重启游戏。

## 使用须知

支持单人游戏、联机房主和 Windows 专用服务器。不支持 Linux 服务器。

备份或迁移存档时，请同时保留本 Mod 目录下的 `Jobs` 文件夹，其中保存未完成制作任务所需的数据；专用服务器请备份服务器端的 `Jobs`。任务取消、保存后恢复和手柄操作仍需进一步实机验证。
