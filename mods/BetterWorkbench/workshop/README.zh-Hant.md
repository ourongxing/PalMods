# 更好的工作台

1.0.0 · ourongxing

同一座工作台內若缺少中間素材，會自動計算製作這些素材所需的原料。另支援素材清單捲動與即時分解。

製作時優先使用持有的中間素材，不足的部分則依該工作台已解鎖的配方展開。點選配方詳情中的成品持有數量，即可切換至分解模式。選擇批次數並確認後，會按完整配方批次消耗成品，將原配方的素材全數返還至背包。

設定檔：`Scripts/config.lua`。`Disassembly.Language` 預設為 `auto`，跟隨遊戲語言；也可指定 `zh-Hans`、`zh-Hant`、`ja` 或 `en`。道具名稱沿用遊戲內的譯名。

分解目前支援單人遊戲及多人遊戲的主機端。多人製作任務定義的同步尚未實作；道具扣除、控制器操作、素材返還與讀取存檔後的還原仍需進行遊戲內驗證。未完成任務的 `Jobs/*.bwj` 請與存檔一併保留。

請先訂閱並啟用必要模組：UE4SSExperimentalPW。接著在遊戲的模組管理中啟用本模組，並重新啟動遊戲。
