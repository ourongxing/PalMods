# CloseRangeBurstSkills

通过 PalSchema 将熔岩爆发（Eruption）、岩爆（Tremor）、毒雨（BubbleShower）的 AI 最大施放距离统一设为 50 游戏单位（约 0.5 米）。

配置位于 [mod/raw/close_range_burst_skills.json](mod/raw/close_range_burst_skills.json)，安装说明及行为限制见 [mod/README.txt](mod/README.txt)。

依赖 PalSchema 和与当前 Palworld 版本匹配的 RE-UE4SS。将 `mod/` 内的全部内容复制到游戏的 `Mods/NativeMods/UE4SS/Mods/PalSchema/mods/CloseRangeBurstSkills/`，然后完全重启游戏。

本 mod 只修改最大施放距离；实际 AI 行为和技能命中效果需要在游戏中验证。
