# Custom Presets

1.0.1 · ourongxing

> Improved background performance.

---

Save and reuse world settings and character appearances.

## Usage

- World settings: save, switch or delete presets at the bottom of custom settings.
- Character appearances: save in the character editor's Presets category; click a thumbnail to apply.
- Save updates the selected preset. Add saves a new named preset; duplicate names are allowed.
- Opening settings preserves current edits without applying another preset.

Uses existing game options; adds no models, hairstyles or outfits. Character names and equipment are excluded.

## Installation

Enable UE4SSExperimentalPW and Custom Presets, then restart the game. Client only; controller support is untested.

## Data and languages

Data is stored in `%LOCALAPPDATA%/Pal/Saved/CustomPresets/presets/`: one file per preset, plus character thumbnails. Backups are in the adjacent `backups/` folder. Copy the presets folder when moving computers; no automatic cloud sync.

Follows the game language. Supports English, Simplified Chinese, Traditional Chinese and Japanese.
