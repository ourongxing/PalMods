# Custom Presets / カスタムプリセット

1.0.0 · ourongxing

ワールドのカスタム設定とキャラクターの外見を保存し、次回から選ぶだけで再利用できます。

## 機能と使い方

- ワールド設定：保存、切り替え、上書き、削除が可能です。標準の難易度プリセットは変更しません。
- 外見設定：キャラクター編集画面の「プリセット」カテゴリで外見を保存し、上半身のサムネイルから選択できます。
- 新規保存はゲーム標準の名前入力画面を使用します。初期名は Custom Preset で、同名も使用できます。
- 画面を開いても現在の編集内容を保持します。削除後は前のプリセット、なければ次を選択します。
- 外見の変更時は未保存の表示が出ます。更新するには上書き保存してください。
- ゲームの言語に従い、日本語、英語、簡体字中国語、繁体字中国語に対応します。

既存の設定を保存する Mod です。モデル、顔、髪型、衣装は追加せず、スライダーの範囲も変更しません。キャラクター名、装備、セーブデータの識別情報は含まれません。外見の確定・キャンセルはゲーム標準の操作で行います。

## 導入

1. 前提 Mod の UE4SSExperimentalPW を有効にします。
2. ゲームの Mod 管理で Custom Presets を有効にします。
3. ゲームを完全に終了してから再起動します。

## 保存データ

プリセットと画像はインストール先と別の `%LOCALAPPDATA%/Pal/Saved/CustomPresets/presets/` に保存されます。別の PC に移す際はバックアップしてください。自動クラウド同期機能はありません。

プリセットごとに名前と全設定を `world-N.preset` または `character-N.preset` に保存します。外見の画像は同じ番号の `character-N.png` に別保存し、バックアップは隣の `../backups/` フォルダーに保存します。

クライアント用 UI Mod のため、専用サーバーへの導入は不要です。開発中にキーボードとマウスで確認していますが、コントローラー操作は未検証です。
