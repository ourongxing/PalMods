# Custom Presets / カスタムプリセット

1.0.0 · ourongxing

ワールド設定とキャラクターの外見を保存・再利用できます。

## 使い方

- ワールド設定：カスタム設定画面の下部で保存・切り替え・削除。
- 外見：キャラクター編集画面の「プリセット」で保存し、サムネイルをクリックして適用。
- 保存は選択中のプリセットを更新。新規追加は名前を付けて別保存します。同名も使用できます。
- 設定画面を開いても編集中の内容は保持されます。

既存のゲーム設定のみを保存します。モデル・髪型・衣装の追加はありません。キャラクター名と装備は保存対象外です。

## 導入

UE4SSExperimentalPW と Custom Presets を有効にし、ゲームを再起動してください。クライアント専用。コントローラー操作は未検証です。

## データと言語

保存先は `%LOCALAPPDATA%/Pal/Saved/CustomPresets/presets/`。プリセットごとに1ファイル、外見は画像も保存します。バックアップは隣の `backups/` に保存します。PC の移行時はプリセットフォルダーをコピーしてください。自動クラウド同期はありません。

ゲームの言語に従い、日本語・英語・簡体字中国語・繁体字中国語に対応します。
