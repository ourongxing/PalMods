# Custom Presets / 自定义预设

1.0.1 · ourongxing

> 优化后台性能。

---

保存并复用世界设置和人物外观。

## 使用

- 世界设置：在自定义设置底部保存、切换或删除预设。
- 人物外观：在人物编辑器的“预设”分类保存外观，点击缩略图应用。
- “保存当前预设”更新所选预设；“添加为新预设”命名后另存，允许同名。
- 打开设置保留当前修改，不自动套用其他预设。

仅保存游戏已有选项，不新增模型、发型或服装。人物名称和装备不包含在预设中。

## 安装

启用 UE4SSExperimentalPW 和 Custom Presets，然后重启游戏。仅客户端需要安装；手柄操作未验证。

## 数据与语言

数据位于 `%LOCALAPPDATA%/Pal/Saved/CustomPresets/presets/`。每个预设一个文件，人物另配缩略图；备份位于相邻的 `backups/`。换电脑时复制预设文件夹，无自动云同步。

界面跟随游戏语言，支持简体中文、繁体中文、英语和日语。
