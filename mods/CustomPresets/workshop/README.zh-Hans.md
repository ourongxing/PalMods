# Custom Presets / 自定义预设

1.0.0 · ourongxing

保存并复用自定义世界设置与人物外观，下次直接选择，不必重新调整。

## 功能与使用

- 世界预设：保存、切换、更新或删除自定义设置，不修改原版难度预设。
- 人物预设：在人物编辑器的“预设”分类保存当前外观，通过上半身缩略图卡片选择已有预设。
- 新增时使用游戏原生命名弹窗，默认名称为 Custom Preset，允许同名。
- 打开设置时保留当前修改；删除后优先选上一个，没有则选下一个。
- 修改人物预设后显示未保存提示，需要主动保存才会更新预设。
- 界面跟随游戏语言，支持简体中文、繁体中文、英语和日语。

本 Mod 仅保存游戏已有选项，不新增人物模型、脸型、发型或服装，也不扩展滑块范围。人物名称、装备和存档身份不包含在外观预设中。最终采用或取消外观仍使用游戏原本的按钮。

## 安装

1. 启用前置 Mod：UE4SSExperimentalPW。
2. 在游戏的 Mod 管理中启用 Custom Presets。
3. 完全退出并重新启动游戏。

## 预设数据

预设和预览图保存在 `%LOCALAPPDATA%/Pal/Saved/CustomPresets/presets/`，独立于安装目录。更换电脑时备份此文件夹；本 Mod 不提供自动云同步。

每个预设单独保存为 `world-N.preset` 或 `character-N.preset`，包含名称和全部参数。人物另配一张同编号的 `character-N.png` 缩略图，备份统一放在旁边的 `../backups/` 文件夹。

这是客户端界面 Mod，专用服务器无需安装。开发期间已验证键鼠操作，手柄导航仍待验证。
