# Custom Presets / 自訂預設

1.0.1 · ourongxing

儲存並重用世界設定與人物外觀。

## 使用

- 世界設定：在自訂設定底部儲存、切換或刪除預設。
- 人物外觀：在人物編輯器的「預設」分類儲存外觀，點選縮圖套用。
- 「儲存目前預設」更新所選預設；「新增為預設」命名後另存，允許同名。
- 開啟設定會保留目前修改，不自動套用其他預設。

僅儲存遊戲既有選項，不新增模型、髮型或服裝。人物名稱與裝備不包含在預設中。

## 安裝

啟用 UE4SSExperimentalPW 與 Custom Presets，然後重新啟動遊戲。僅用戶端需要安裝；控制器操作未驗證。

## 資料與語言

資料位於 `%LOCALAPPDATA%/Pal/Saved/CustomPresets/presets/`。每個預設一個檔案，人物另附縮圖；備份位於相鄰的 `backups/`。更換電腦時複製預設資料夾，無自動雲端同步。

介面跟隨遊戲語言，支援繁體中文、簡體中文、英語與日語。
