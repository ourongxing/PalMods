# Custom Presets / 自訂預設

1.0.0 · ourongxing

儲存並重用自訂世界設定與人物外觀，下次直接選用，不必重新調整。

## 功能與使用

- 世界預設：儲存、切換、更新或刪除自訂設定，不修改原版難度預設。
- 人物預設：在人物編輯器的「預設」分類儲存目前外觀，透過上半身縮圖卡片選用已有預設。
- 新增時使用遊戲原生命名視窗，預設名稱為 Custom Preset，允許同名。
- 開啟設定時保留目前修改；刪除後優先選上一個，沒有則選下一個。
- 修改人物預設後顯示尚未儲存提示，需要主動儲存才會更新預設。
- 介面跟隨遊戲語言，支援繁體中文、簡體中文、英語與日語。

本 Mod 僅儲存遊戲既有選項，不新增人物模型、臉型、髮型或服裝，也不擴充滑桿範圍。人物名稱、裝備與存檔身分不包含在外觀預設中。最終採用或取消外觀仍使用遊戲原有按鈕。

## 安裝

1. 啟用前置 Mod：UE4SSExperimentalPW。
2. 在遊戲的 Mod 管理中啟用 Custom Presets。
3. 完全結束並重新啟動遊戲。

## 預設資料

預設與預覽圖儲存在 `%LOCALAPPDATA%/Pal/Saved/CustomPresets/presets/`，獨立於安裝目錄。更換電腦時請備份此資料夾；本 Mod 不提供自動雲端同步。

每個預設單獨儲存為 `world-N.preset` 或 `character-N.preset`，包含名稱與全部參數。人物另配同編號的 `character-N.png` 縮圖，備份放在相鄰的 `../backups/` 資料夾。

這是用戶端介面 Mod，專用伺服器不需要安裝。開發期間已驗證鍵鼠操作，控制器導覽仍待驗證。
