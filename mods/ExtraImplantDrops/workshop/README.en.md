# Extra Implant Drops

1.0.0 · ourongxing

Pals can drop additional implants matching their passive skills when death or butchering generates loot. Normal material drops remain unchanged.

Supports 28 implants, each with an independent 50% default drop chance. Base quantity is 1, affected by game drop bonuses and world settings.

Configuration: config.ini. DropChance=0.5 sets the probability from 0 to 1; [Implants] toggles individual implants. Restart the game after changes.

Subscribe to and enable UE4SSExperimentalPW, then enable this mod in the game Mod Management menu, fully exit the game, and restart it.
