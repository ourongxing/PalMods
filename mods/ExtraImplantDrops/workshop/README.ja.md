# インプラント追加ドロップ

1.0.0 · ourongxing

パルの死亡や解体時に、パッシブスキルに対応するインプラントが追加でドロップすることがあります。

## 機能と使い方

- 28 種類のインプラントに対応し、対象のパッシブスキルごとに独立して抽選します。
- 初期ドロップ確率は 50%、基本個数は 1 個です。
- 個数にはゲーム内のドロップボーナスとワールド設定が反映されます。
- 通常の素材ドロップはそのままです。

## 導入方法

1. 必要な Mod（UE4SSExperimentalPW）をサブスクライブして有効にします。
2. ゲーム内の Mod 管理で本 Mod を有効にします。
3. ゲームを完全に終了してから、再起動してください。

## 設定

Palworld のインストール先にある `Mods/NativeMods/UE4SS/Mods/ExtraImplantDrops/config.ini` を編集し、保存後にゲームを完全に終了して再起動してください。

- `[Harvest]` の `DropChance=0.5`：ドロップ確率です。範囲は 0～1 で、0 はドロップなし、1 は抽選に必ず成功します。
- `[Implants]`：各パッシブスキルに対応するドロップを個別に設定します。1 で有効、0 で無効です。有効でも確率による抽選は行います。
