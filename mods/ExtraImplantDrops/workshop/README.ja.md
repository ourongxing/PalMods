# インプラント追加ドロップ

1.0.0 · ourongxing

パルの死亡や解体でアイテムがドロップする際、パッシブスキルに対応するインプラントが追加でドロップすることがあります。通常の素材ドロップは変更しません。

28 種類に対応し、それぞれ独立して判定します。初期ドロップ確率は 50%、基本個数は 1 個で、ゲーム内のドロップボーナスとワールド設定が反映されます。

設定ファイル：config.ini。DropChance=0.5 は 0～1 の確率、[Implants] は各インプラントの有効・無効を設定します。変更後はゲームを再起動してください。

前提 Mod UE4SSExperimentalPW を購読して有効にし、ゲームの Mod 管理で本 Mod を有効にした後、ゲームを完全に終了して再起動してください。
