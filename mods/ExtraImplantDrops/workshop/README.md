## Report a problem

https://github.com/ourongxing/PalMods/issues

Attach the complete `UE4SS.log` and include reproduction steps, game and mod versions, game language, multiplayer role, and other enabled mods. Without the UE4SS log, I cannot diagnose and fix bugs.

Log location relative to your Palworld installation: `Mods\NativeMods\UE4SS\UE4SS.log`

Example: `G:\SteamLibrary\steamapps\common\Palworld\Mods\NativeMods\UE4SS\UE4SS.log`

Use your own Steam library location. Copy the log before launching the game again.
