# 植入体掉落

1.0.0 · ourongxing

帕鲁死亡或肢解产生掉落物时，有概率额外掉落其词条对应的植入体，不影响原有材料。

支持 28 种植入体，每种独立判定，默认概率 50%。基础数量为 1，受游戏掉落加成和世界设置影响。

配置文件：config.ini。DropChance=0.5 为掉落概率，范围 0～1；[Implants] 可单独开关各植入体。修改后重启游戏。

订阅并启用前置模组 UE4SSExperimentalPW，然后在游戏模组管理中启用本模组，完全退出游戏并重启。
