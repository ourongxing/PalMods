# 植入體掉落

1.0.0 · ourongxing

帕魯死亡或肢解產生掉落物時，有機率額外掉落其詞條對應的植入體，不影響原有材料。

支援 28 種植入體，各自獨立判定，預設機率 50%。基礎數量為 1，受遊戲掉落加成與世界設定影響。

設定檔：config.ini。DropChance=0.5 為掉落機率，範圍 0～1；[Implants] 可個別開關各植入體。修改後重新啟動遊戲。

訂閱並啟用前置模組 UE4SSExperimentalPW，接著在遊戲模組管理中啟用本模組，完全退出遊戲並重新啟動。
