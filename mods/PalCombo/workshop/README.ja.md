# パルの連続攻撃

1.0.0 · ourongxing

プレイヤーのパルがスキルスロット1→2の順で連続攻撃するようになります。スロット3は、次の連続攻撃を始められるまでの間に使います。

スロット1が使用可能で、スロット2も使用可能、またはクールタイムの残り時間が設定値以下になると、連続攻撃を開始します。スロット1のクールタイムが始まったらスロット2を待ち、その間はスロット3を使いません。スロット2のクールタイムが始まると、次の連続攻撃を判定します。ライド中は手動操作になり、降りると自動戦闘に戻ります。

設定：`config.ini` の `EarlyStartSeconds`。初期値は3秒、設定範囲は0～30秒です。0にすると、スロット2のクールタイムが完全に終わるまで待ちます。変更後はゲームを再起動してください。このmodはゲーム内の表示テキストを追加しません。

必要なmod（UE4SSExperimentalPW）をサブスクライブして有効にしてください。その後、ゲームのmod管理でこのmodを有効にし、ゲームを再起動してください。
