# PointBlankBurstSkills

让熔岩爆发、岩爆和毒雨改为贴脸释放。通过 PalSchema 将熔岩爆发（Eruption）、岩爆（Tremor）、毒雨（BubbleShower）的 AI 最大施放距离设为 50 游戏单位（约 0.5 米）。
配置及安装见 [mod/README.txt](mod/README.txt)。

在仓库根目录执行 `python tools/build.py PointBlankBurstSkills`，校验 JSON 并生成
`.build/PointBlankBurstSkills/stage/Mods/PalSchema/mods/PointBlankBurstSkills/`。
