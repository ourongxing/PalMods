# Point-Blank Burst Skills

1.0.0 · ourongxing

Makes Pals move close to their target before using Volcanic Rain, Rockburst, or Poison Shower.

Sets the AI's maximum activation range for these three skills to 50 game units, approximately 0.5 m. Power, cooldowns, attack areas, and damage detection retain their original values.

Configuration: this mod's `raw/point_blank_burst_skills.json` in the PalSchema installation directory. Fully restart the game after changes. If another mod changes the same skills' activation range, the result depends on load order. Skill names retain the game's translations.

Subscribe to and enable the required mods: UE4SSExperimentalPW, PalSchema. Then enable this mod in the game’s Mod Management menu and restart the game.
