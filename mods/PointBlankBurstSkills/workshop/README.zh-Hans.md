# 爆发技能贴脸释放

1.0.0 · ourongxing

让帕鲁靠近目标后再使用熔岩爆发、岩爆和毒雨。

将这三个技能的AI最大施放距离设置为50游戏单位，约0.5米。技能威力、冷却、攻击范围及伤害判定保持原版设置。

配置：PalSchema安装目录中本mod的 `raw/point_blank_burst_skills.json`。修改后完全重启游戏。其他mod若修改同一技能的最大施放距离，最终结果取决于加载顺序。技能名称继续使用游戏官方译名。

先订阅并启用依赖：UE4SSExperimentalPW, PalSchema。然后在游戏的mod管理中启用本mod，并重新启动游戏。
