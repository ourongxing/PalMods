# Quick Butcher

1.1.0 · ourongxing

Skip the player's Meat Cleaver butchering animation while keeping the standard loot.

Equip the Meat Cleaver and select Butcher from the Pal command menu.

## Installation

Subscribe, enable in Mod Management, and restart the game. No prerequisite mods required.

For dedicated servers, install and enable the mod on both the server and each client. The package includes separate Windows dedicated-server resources. Restart the server after updating. The original short settlement delay remains.

## Compatibility

Do not use alongside other mods that change the butchering animation.
