# Quick Butcher / 高速解体

1.1.0 · ourongxing

肉切り包丁を使う際のプレイヤーの解体アニメーションをスキップします。ドロップは通常どおりです。

肉切り包丁を装備し、パル指示メニューから解体を選ぶだけです。

## インストール

サブスクライブして Mod 管理画面で有効にし、ゲームを再起動してください。前提 mod は不要です。

専用サーバーでは、サーバーと各クライアントの両方に導入して有効にしてください。Windows 専用サーバー用の独立したリソースを同梱しています。更新後はサーバーを再起動してください。元の終了処理にある短い精算待ち時間は残ります。

## 互換性

解体アニメーションを変更する他の mod とは併用しないでください。
