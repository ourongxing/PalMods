# 上昇気流

1.0.0 · ourongxing

小型・中型・大型の上昇気流を建築できます。気流の中でジャンプすると、上空へ飛び上がれます。初期設定の高さは8／16／32m、効果範囲の直径は2／4／6mです。範囲が重なる場合は、最も高く飛べる設定が適用されます。

レベル9の古代テクノロジーで、古代テクノロジーポイントを1ポイント使うと3種類すべてを解放できます。各建築に必要な素材は、パルジウムの欠片10個、石30個、古代文明の部品3個です。建築メニューのインフラ／その他から設置できます。完成後は透明になります。解体するには、気流の下部にある土台を狙ってください。

設定：`Scripts/config.lua` の `Small`、`Medium`、`Large`。単位はm、範囲は0.1～1000で、小数も指定できます。変更後はゲームを再起動してください。建築とテクノロジーの表示は、PalSchemaがゲームの言語に合わせて読み込みます。

必要なmod（UE4SSExperimentalPW, PalSchema）をサブスクライブして有効にしてください。その後、ゲームのmod管理でこのmodを有効にし、ゲームを再起動してください。
