# 上升气流

1.0.0 · ourongxing

新增小型、中型和大型上升气流建筑。在气流范围内起跳即可升空。默认升空高度为8／16／32米，效果范围直径为2／4／6米；重叠区域取最高一档。

在第9级古代科技中消耗1个古代科技点，解锁全部三种尺寸。每个建筑需要10帕鲁矿碎片、30石头和3古代文明部件。在建造菜单的基础设施／上升气流分类中放置。建成后透明，拆除时瞄准气流下部的底座。

配置：`Scripts/config.lua` 中的 `Small`、`Medium`、`Large`，单位为米，范围0.1～1000，支持小数。修改后重启游戏。建筑和科技文字由PalSchema跟随游戏语言加载。

先订阅并启用依赖：UE4SSExperimentalPW, PalSchema。然后在游戏的mod管理中启用本mod，并重新启动游戏。
