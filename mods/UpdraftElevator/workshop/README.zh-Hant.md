# 上升氣流

1.0.0 · ourongxing

新增小型、中型與大型的上升氣流建築。在氣流範圍內起跳即可升空。預設升空高度為8／16／32公尺，效果範圍直徑為2／4／6公尺。範圍重疊時，採用最高的升空設定。

在第9級古代科技中花費1點古代科技點，即可解鎖全部三種尺寸。每座建築需要10個帕魯礦碎片、30個石頭及3個古代文明部件。可從建造選單的基礎設施／上升氣流分類放置。完工後建築會變成透明；拆除時，請瞄準氣流下方的底座。

設定：`Scripts/config.lua` 中的 `Small`、`Medium`、`Large`，單位為公尺，範圍0.1～1000，可使用小數。變更後請重新啟動遊戲。建築與科技文字由PalSchema依遊戲語言載入。

請先訂閱並啟用必要模組：UE4SSExperimentalPW, PalSchema。接著在遊戲的模組管理中啟用本模組，並重新啟動遊戲。
